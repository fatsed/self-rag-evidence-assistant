# Contributing

Thanks for checking out this project.

This is a student project, so any small improvement is welcome.

## How to contribute

1. Create a new branch.
2. Make your changes.
3. Test the project if possible.
4. Open a Pull Request and briefly explain what you changed.

## Notes

- Keep the code simple and readable.
- Try to follow the current project structure.
- Please do not commit API keys or private files.

## Issues

If you notice a bug or have an idea, feel free to open an Issue.
